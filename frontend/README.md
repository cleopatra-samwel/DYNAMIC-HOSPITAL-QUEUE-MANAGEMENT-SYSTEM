# Hospital Queue Management System — Frontend

React + Vite + Tailwind CSS + Ant Design. Redux Toolkit for auth state,
Axios for API calls, Howler.js for pre-recorded audio playback (wired from
Phase 8), Laravel Echo + Pusher-protocol client for Reverb (wired from
Phase 7).

## Setup

```bash
npm install
cp .env.example .env
```

Edit `.env` if your backend isn't at `http://localhost:8000`, then:

```bash
npm run dev
```
